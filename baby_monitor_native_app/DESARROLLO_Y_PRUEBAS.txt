----------------------------------------------------------------
C.1 AUTENTICACIÓN BIOMÉTRICA POR RECONOCIMIENTO FACIAL
----------------------------------------------------------------
Descripción:
  Implementación de un sistema de autenticación segura mediante
  reconocimiento facial usando la cámara frontal del dispositivo.
  Se integra con el servicio de Supabase para validar identidades
  de tutores y personal autorizado.

Funcionalidades incluidas:
  - Captura de foto en tiempo real con la cámara frontal.
  - Extracción de embeddings faciales (vectores biométricos).
  - Comparación de embeddings contra la base de datos de Supabase.
  - Umbral de similitud configurable (porcentaje de coincidencia).
  - Bloqueo de acceso tras N intentos fallidos consecutivos.
  - Registro de logs de acceso (exitoso / fallido) con timestamp.

Tecnologías utilizadas:
  - Flutter: camera, google_ml_kit o face_recognition
  - Backend: Supabase (PostgreSQL + Storage)
  - Seguridad: AES-256 para almacenamiento de embeddings

Estado: En desarrollo

----------------------------------------------------------------
C.2 REGISTRO Y GESTIÓN DE NIÑOS (PERFILES INFANTILES)
----------------------------------------------------------------
Descripción:
  Módulo para registrar los datos básicos de cada niño bajo
  cuidado, incluyendo foto de perfil, datos personales y
  contactos de emergencia vinculados.

Funcionalidades incluidas:
  - Formulario de alta de perfil infantil (nombre, fecha de
    nacimiento, alergias, condiciones médicas relevantes).
  - Carga y almacenamiento de foto de perfil en Supabase Storage.
  - Asignación de tutores/guardias autorizados por niño.
  - Edición y baja lógica de perfiles.
  - Listado con búsqueda y filtros por nombre o grupo.

Tecnologías utilizadas:
  - Flutter: image_picker, flutter_form_builder
  - Backend: Supabase (tabla: children, tabla: guardians)

Estado: En desarrollo

----------------------------------------------------------------
C.3 CONTROL DE ACCESO (ENTRADA Y SALIDA)
----------------------------------------------------------------
Descripción:
  Módulo que registra y controla el ingreso y egreso de los
  niños al centro de cuidado, validado mediante reconocimiento
  facial del tutor autorizado.

Funcionalidades incluidas:
  - Escaneo facial del tutor al momento de entrada/salida.
  - Confirmación visual del niño a retirar.
  - Registro de fecha, hora y tipo de evento (entrada/salida).
  - Notificación push al tutor secundario al momento del retiro.
  - Historial de movimientos por niño y por fecha.

Tecnologías utilizadas:
  - Flutter: local_notifications, supabase_flutter
  - Backend: Supabase (tabla: access_log)
  - Notificaciones: Firebase Cloud Messaging (FCM)

Estado: Pendiente

----------------------------------------------------------------
C.4 MONITOREO EN TIEMPO REAL (CÁMARA / STREAM)
----------------------------------------------------------------
Descripción:
  Visualización en vivo desde cámaras instaladas en las salas
  del centro, accesible únicamente para personal autorizado y
  tutores registrados.

Funcionalidades incluidas:
  - Visualización de stream de video en la app.
  - Selección de sala/cámara activa.
  - Grabación de clips bajo demanda (almacenados en nube).
  - Control de acceso por rol (admin / tutor / personal).

Tecnologías utilizadas:
  - Flutter: webrtc o video_player
  - Backend: Supabase Storage / servidor RTSP externo
  - Seguridad: JWT + RLS (Row Level Security) en Supabase

Estado: Pendiente

----------------------------------------------------------------
C.5 PANEL DE ADMINISTRACIÓN
----------------------------------------------------------------
Descripción:
  Interfaz para el administrador del centro con acceso completo

Funcionalidades incluidas:
  - Dashboard con métricas del día (ingresos, egresos, alertas).
  - Gestión de cuentas de personal y tutores.
  - Configuración de umbrales de reconocimiento facial.
  - Exportación de reportes en PDF/CSV.
  - Gestión de grupos y salas.

Tecnologías utilizadas:
  - Flutter: fl_chart, pdf (dart)
  - Backend: Supabase (vistas y funciones RPC)

Estado: Pendiente

----------------------------------------------------------------
C.6 NOTIFICACIONES Y ALERTAS
----------------------------------------------------------------
Descripción:
  Sistema de notificaciones automáticas ante eventos relevantes
  dentro de la app (acceso no autorizado, retiro de niño, etc.).

Funcionalidades incluidas:
  - Notificación push en tiempo real vía FCM.

Tecnologías utilizadas:
  - Firebase Cloud Messaging (FCM)

D.4 PRUEBAS DE SEGURIDAD (Security Tests)
----------------------------------------------------------------
Descripción:
  Verificación de que los datos sensibles y el acceso al sistema
  están adecuadamente protegidos.

Casos de prueba planificados:

  [ST-01] Acceso sin autenticación
    - Verificar que las rutas protegidas redirigen al login.

  [ST-02] Intentos fallidos de reconocimiento facial
    - Verificar bloqueo tras 3 intentos fallidos consecutivos.

    - Verificar que los embeddings NO se almacenan en texto plano.
    - Verificar cifrado AES-256 aplicado.

  [ST-04] RLS en Supabase
    - Verificar que un tutor NO puede ver datos de otro tutor.
    - Verificar que sólo el admin accede a todos los registros.

  [ST-05] Tokens JWT expirados
    - Verificar que sesiones vencidas son rechazadas correctamente.

Herramientas: OWASP Mobile Testing Guide (MSTG), Postman (API)
